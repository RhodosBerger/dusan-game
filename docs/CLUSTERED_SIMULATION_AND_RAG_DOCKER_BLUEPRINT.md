# Architectural Blueprint: Clustered Simulation & RAG Docker Deployment

This document defines the containerization architecture and Docker Compose orchestration for running clustered decoupled headless simulations alongside the AI external narrative RAG memory service.

---

## 1. Multi-Container Clustered Architecture

The clustered deployment runs multiple headless simulator instances (nodes) synchronizing state and assets via P2P connections, alongside an AI RAG container that reads the generated combinatorial narrative datasets.

```
                  ┌──────────────────────────────────────────┐
                  │          Shared Volume Mount             │
                  │   (/scratch/narrative_rag_dataset.jsonl) │
                  └──────────────────────────────────────────┘
                                ▲              ▲
       (Writes Narrative Data) │              │ (Reads RAG Dataset)
                               │              │
┌──────────────────────────────┴─┐      ┌─────┴──────────────────────┐
│  Headless Simulator Cluster   │      │   AI Narrative RAG Service │
│  - simulator-node-1 (Leader)  │      │   - Python Vector Indexer  │
│  - simulator-node-2 (Follower)│      │   - Dialogue Generator API │
└────────────────────────────────┘      └────────────────────────────┘
     ▲                      ▲
     └─ P2P State Transfer ─┘
         (REST Ports 3001/3002)
```

## 2. Docker Container Specifications

### A. Clustered Headless Simulator Node (`Dockerfile.simulator`)
This node runs the Express Node backend in headless mode, performing simulations and executing neighbor-to-neighbor replication.

```dockerfile
# packages/server/Dockerfile.simulator
FROM node:20-alpine AS builder

WORKDIR /usr/src/app

# Cache dependency layer (Rule 5 compliant)
COPY package.json yarn.lock ./
COPY packages/shared/package.json ./packages/shared/
COPY packages/server/package.json ./packages/server/

RUN yarn install --frozen-lockfile

# Copy source code and compile
COPY . .
RUN yarn workspace @dusan-game/shared build
RUN yarn workspace @dusan-game/server build

# Production image execution stage
FROM node:20-alpine

WORKDIR /usr/src/app

COPY --from=builder /usr/src/app /usr/src/app

# Non-root execution for cybersecurity safeguard
USER node

ENV NODE_ENV=production
ENV PORT=3001
ENV HEADLESS_MODE=true

EXPOSE 3001

CMD ["node", "packages/server/dist/server.js"]
```

### B. AI Narrative RAG Service (`Dockerfile.rag`)
This service runs a Python-based semantic vector engine that consumes the `.jsonl` dataset generated by the simulation nodes.

```dockerfile
# packages/ai-rag/Dockerfile.rag
FROM python:3.11-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# Cache pip dependency layer
COPY packages/ai-rag/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy source code
COPY packages/ai-rag/ .

# Non-root execution
RUN useradd -m appuser && chown -R appuser:appuser /app
USER appuser

ENV PORT=5000
ENV MEMORY_FILE_PATH=/scratch/narrative_rag_dataset.jsonl

EXPOSE 5000

CMD ["python", "app.py"]
```

## 3. Clustered Orchestration (`docker-compose.sync.yml`)

This Compose configuration sets up the peer-to-peer simulator nodes and binds them to the shared directory volume mount.

```yaml
version: '3.8'

services:
  # Clustered Node 1: Leader Simulator
  simulator-node-1:
    build:
      context: .
      dockerfile: packages/server/Dockerfile.simulator
    environment:
      - PORT=3001
      - NODE_ID=node_leader
      - PEER_NODES=http://simulator-node-2:3002
    ports:
      - "3001:3001"
    volumes:
      - shared-scratch-data:/usr/src/app/packages/server/scratch
    networks:
      - dusan-sync-network

  # Clustered Node 2: Follower Simulator (P2P target)
  simulator-node-2:
    build:
      context: .
      dockerfile: packages/server/Dockerfile.simulator
    environment:
      - PORT=3002
      - NODE_ID=node_follower_01
      - PEER_NODES=http://simulator-node-1:3001
    ports:
      - "3002:3002"
    volumes:
      - shared-scratch-data:/usr/src/app/packages/server/scratch
    networks:
      - dusan-sync-network

  # AI Narrative RAG Service: Memory Searcher
  ai-rag-service:
    build:
      context: .
      dockerfile: packages/ai-rag/Dockerfile.rag
    environment:
      - MEMORY_FILE_PATH=/scratch/narrative_rag_dataset.jsonl
    ports:
      - "5000:5000"
    volumes:
      - shared-scratch-data:/scratch:ro # Read-Only mount to prevent corruption
    depends_on:
      - simulator-node-1
      - simulator-node-2
    networks:
      - dusan-sync-network

volumes:
  shared-scratch-data:
    driver: local

networks:
  dusan-sync-network:
    driver: bridge
```
